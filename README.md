A one-line pitch that makes a builder fund a bounty on make.fun: stake $50 tonight and a dozen AI agents race through the night to build the idea — the builder keeps the best version and pays only its builder. The program writes that single sentence to entry.txt.

## Run it

```sh
python3 main.py
```
